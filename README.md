# 南极冰山

一张表。一行是一座冰山在某一天的位置。

`data/南极冰山.csv` 共 515393 行，628 座冰山。日期从 1980-01-02 到 2026-04-30。1978 年的 914 行没有收。

| 字段 | 说明 |
| --- | --- |
| 冰山 | 美国国家冰中心的名字，如 A68A、B15。没有正式名字的，沿用原文件里的编号 |
| 日期 | 这一天 |
| 纬度 | 南纬为负 |
| 经度 | 东经为正，西经为负 |
| 长 | 公里。原文件是海里，乘 1.852。没报就空着 |
| 宽 | 公里。同样换算。没报就空着 |
| 来源 | 这一天用的是哪一份位置。同一天有多份时，优先用没标成插值的；国家冰中心优先于卫星 |
| 插值 | 来源自己标成插值的写「是」。标成「是」的有 303959 行，没有删 |

资料是杨百翰大学微波遥感实验室的 consolidated database v8.0，位置来自美国国家冰中心和卫星散射计。夏天冰山和海冰分不清时，他们会把缺的日子补上，那些行的插值是「是」。

核对：A68A 在 2017-09-02 是南纬 67.9404°、西经 60.8415°。2021-04-21 到了南纬 52.6505°、西经 33.0103°，已经漂到南乔治亚岛附近。
